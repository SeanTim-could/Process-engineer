# 工艺工程师工作台

通过网址打开，每个人的数据独立保存在自己的浏览器中。需要分享时，导出文件发给对方，由对方导入使用。登录身份通过 Supabase 账号服务验证。

界面、示例和导入模板使用生产指标、质量指标、资源消耗、损失分析和统计监测等通用分类。资源指标可按各装置的实际名称和单位填写；已有装置名称、用户自定义指标、导入数据和历史快照保留原样，旧版表头仍可识别。

## 发布网址

将本目录中的 `index.html`、`workbench.html`、`assets/`、`.nojekyll` 和 `启动工程师工作台.html` 一起提交到 GitHub 的 `main` 分支。在支持 GitHub Pages 的仓库中：

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 选择 **main** 分支和 **/ (root)** 目录，点击 **Save**。
4. 等待部署完成，使用 Pages 页面显示的实际网址。

本仓库的默认网址通常为 `https://seantim-could.github.io/Process-engineer/`；只有 GitHub Pages 部署成功后才能访问。将网址发给对方即可，无需把 HTML 文件逐人发送。`index.html` 是轻量登录页，在整套图表代码加载前就能显示。登录后进入 `workbench.html`，它使用带内容指纹的独立脚本与样式文件，便于缓存；登录页会在空闲时预取这些资源。旧版中文网页地址也会在网站上转到新入口。

## 保存、另存为与打开

顶部操作按常用办公软件的文件逻辑工作：

- **保存 / Ctrl+S**：第一次选择JSON文件名与位置，之后写回当前文件。
- **另存为 / Ctrl+Shift+S**：选择另一位置或文件名，保存完整工作空间，并将新文件作为当前文件；旧文件保留原内容。
- **打开**：选择已有JSON工作台文件（兼容旧版完整备份），确认后打开。替换前自动下载当前工作空间副本，成功后将选中的文件作为当前文件，后续保存可写回该文件。

当前文件名和未保存状态显示在顶部。浏览器内的自动恢复缓存继续工作，保存原始数据和未完成的分析设置；文件仅在你点击保存或另存为时写入磁盘。分析设置也有按账号隔离的同步恢复镜像，尽量避免刚输入就刷新造成丢失。清理浏览器存储前请保存文件。

直接选择位置并写回文件需要支持 File System Access 的 Chrome / Edge，以及 HTTPS 网站或 localhost。浏览器可能在重新打开后要求再次授予所选文件的写入权限。不支持该功能的浏览器会明确进入下载副本模式，保存时下载JSON副本，不能自动覆盖以前下载的文件。文件位置的权限句柄只保存在当前账号的本机浏览器中，不会打包到JSON分享给其他人。

取消选择或写入失败时保持当前文件关联。检测到文件被外部程序修改，或其他工作台窗口切换了当前文件时，会停止写入并提示核对，避免覆盖其他修改。保存的JSON包含数据、公式、报告、个人设置、作图区和分析工作状态；登录姓名与工号仍由账号服务决定。

## 分享数据

### 管理员定期收集并加入数据

1. 用户点击顶部 **另存为**，将导出的 JSON 文件交给管理员。
2. 管理员登录后，点击顶部 **加入数据**，选择文件，核对 **提交人工号**，再点击 **预览加入内容**。
3. 核对新增装置、记录、月报及冲突提示后，点击 **确认加入，保留已有数据**。工作台先下载当前汇总的备份，再保存合并结果并刷新。

装置按提交人工号区分，例如“反应装置 · e001”，避免不同用户都有“默认装置”时混在一起。同一人每次必须使用相同工号；后续备份会追加到之前的来源装置。重复记录去重，空缺值补充，冲突保留已有值。指标名称、单位或公式定义有冲突时保留已有列定义及该列数据；日报自定义指标口径冲突时保留该指标已有数据。未完成导入的数据集会跳过。

合并包括日报、生产/LIMS图表数据、计算公式及跨装置引用、关注记录、导入历史和月报快照；保留管理员的姓名、工号、主题、文件索引和当前筛选设置。不会同步用户后续的修改或删除，后续数据需要再次收集加入。不同用户的装置保持独立，可在工作台中切换、对比和跨装置计算。当前工作台的30个装置、100个日报自定义指标及各类数据量上限仍适用；超过上限或文件有误时整次加入不保存。

此入口仅供已登录的管理员使用，无需调整 Supabase 表或函数。**打开** 用于打开已有工作台文件并整体替换当前工作空间，请按用途选择。浏览器若拦截备份下载，请先手动完整备份并确认文件保存。

### 分享整个工作空间

1. 发送方在网页顶部点击 **另存为**，下载 JSON 文件，再通过聊天、邮件等方式发给对方。
2. 接收方打开工作台网址，点击顶部 **打开**，选择收到的 JSON 文件。
3. 核对恢复提示并确认。工作台会先下载接收方当前数据的备份，再替换工作空间。

完整备份包含历史数据、指标配置、计算公式、关注记录、月报，以及个人资料、主题色和文件索引。分享前请确认这些内容都适合提供给对方。文件索引只保存地址，不包含被索引的本机文件本身。

**打开文件会替换当前工作空间，不会合并。** 接收方应保留自动下载的恢复前备份。浏览器若拦截下载，请先手动点击“另存为”并确认文件已保存，再执行恢复。

### 只分享部分数据

在 **数据中心** 选择数据，点击 **导出所选数据**，把 CSV 文件发给对方。接收方点击 **导入数据**，选择文件及目标装置，按界面提示核对并保存。

此方式用于导入表格数据，不等同于完整备份：不会一起带走全部个人资料、工作空间设置、计算公式或月报快照。导入遇到同名指标、相同时间及分组的值冲突时，按界面提示核对新旧值。

## 数据保存

- 数据保存在当前浏览器的本地数据库中，不会因为打开网址就自动分享给其他人，也不会自动上传到 GitHub。
- 每个人独立编辑；文件分享后各自保留一份，不会自动同步后续修改。
- 请使用 Chrome 或 Edge 的普通窗口，定期导出完整备份。无痕窗口、清理浏览器数据、更换电脑或网址后，本地数据可能不可用，需要用备份迁移。
- 如果顶部出现“临时模式”，请在关闭窗口前完成备份。
- 从本机 HTML 文件切换到网站时，请先在旧页面导出完整备份，再在网站恢复。
- 本机或共享盘文件路径不会随网站发布变为公开文件；对方需要另行获得文件及访问权限。

## 管理员统一发放账号

本工作台已连接 Supabase 账号服务，通过管理员发放的工号和密码登录。管理员可绑定姓名、工号并生成初始密码，使用者首次登录必须改密。登录后按账号划分本机工作空间；不会自动同步生产数据或上传本机文档。旧版未登录的数据仍保留在原本机数据库中，可在 **账号管理 → 导出旧版本机备份** 导出，再通过顶部 **打开** 迁入当前账号。具体配置和首次管理员创建步骤见 [账号服务启用说明](账号服务启用说明.md)。

## 跨装置计算指标

在 **数据中心 → 新增计算指标** 中，先填写名称、输出单位和公式，再在“点击指标插入引用”区域选择 **引用装置 → 数据分组（生产 / LIMS）→ 分组 / 采样点**，点击指标按钮插入引用。其他装置需要先在当前工作空间导入数据；无需切换当前装置即可引用。

- 计算结果保存在当前装置；跨装置引用同时保存来源数据集、装置、指标和采样点，不会因为不同装置有相同指标名或编号而混用。
- 选择生产时间基准时，使用当前装置、当前分组的生产时间；选择 LIMS 基准时，使用所选主检验位点的采样时间。跨装置按最近时间匹配，距离相同取较早记录。
- 最大匹配时间差可调整；超出限制、最近记录为空、来源被删除或归档时，结果留空并说明原因。LIMS 引用仍遵守共同覆盖时间范围。
- 预览会列出实际匹配的装置、采样时间和时间差。确认后再保存；预览后来源数据有变化时，需要重新预览。
- 引用装置后续导入或修改数据后，会自动重新计算相关指标和后续公式；历史月报快照保持生成时的数据。跨装置循环引用会被拦截。
- 公式按保存时的各引用单位计算，输出单位由你指定，不自动推导量纲。不同单位相加时请明确换算，例如 `kg/h + t/h * 1000`。后续把来源单位改成兼容单位时，会按原引用单位换算，保持已有公式含义。

公式支持英文圆括号 `()`、中文圆括号 `（）` 及多层嵌套，例如 `（[指标A] + [指标B]） / [指标C]`；支持函数参数中的中文逗号，以及 `×`、`÷`。先计算括号内的内容，再按运算优先级计算。指标名称仍用 `[显示名称]` 引用，引用内部的中文括号和标点保持原样。编辑器提供 **插入括号 / 包住选中内容**，并提示语法错误；指标存在性、引用单位和结果需通过预览核对。乘法须显式填写 `*` 或 `×`，不把相邻括号自动当作乘法。

完整备份包含这些跨装置绑定。要让另一台电脑继续计算，请分享完整备份；单独导出一个装置的 CSV 不会带走其他装置和公式配置。

## 数据分析与自由作图

左侧菜单按 **运行概览、数据分析、数据管理、文档与个人** 四组组织。点击一级标题可展开或收起，原有自动图表、多指标对比、关系分析、LIMS、月报、数据中心和个人中心功能仍可进入。

### 时序分析

在 **数据分析 → 时序分析** 选择装置的完整指标或日报指标、分析指标、采样分组和时间范围。支持生产与LIMS指标，生成个体值时序图和移动极差 MR 图，可填写规格限，查看均值、样本标准差及3σ控制限以外点数。日期与时间统一按北京时间解释，结束分钟包含整分钟。

缺失值不补零，明确的空读数会打断曲线和移动极差；其他指标独有的采样时间不算当前指标的缺失读数。各采样分组分别画线、计算移动极差。选择“全部分组”会合并统计，能力分析建议选择同一工况、同一采样点。

时序页面同时提供 **过程能力分析**：沿用上方规格限、指标、分组及时间范围，显示 Cp、Cpk、Pp、Ppk、整体/组内标准差、实际超规格百分比、整体/组内正态预测PPM，以及 Anderson–Darling 正态性检验。直方图叠加整体和组内正态拟合曲线；单边规格不显示 Cp / Pp，空样本、零波动或样本不足时显示“—”。无规格限时保留统计和分布图，提示填写规格限。

**过程能力子组大小**默认为1，按I-MR估计组内标准差；2–100按同采样分组时间顺序划分子组，合并方差并作c4修正。该设置会自动保存，不改变时序I-MR图的个体值口径。能力表可导出CSV，也随分析报告导出。指数应结合过程稳定性、分布形态和实际合理子组解释。

### 自选并排除异常点

时序分析、前后能力分析、自由作图及保存的作图区图表、运行总览、趋势分析、LIMS和自动图表提供 **删除异常点** 按钮。点击后打开原始采样值预览：直接点选图上的读数，或按时间、分组、数值查找并在明细中勾选，可跨页选择，最后点击 **确认删除所选点**。汇总柱、直方和箱线图也从原始读数中选择，不把一个汇总柱误当作一条原始记录。

排除只作用于本账号的图表与实时统计，同一来源、指标和采样读数在各处保持一致。原始数据库和JSON中的测量值不改写，公式仍使用原始输入，已生成的月报快照保留。删除一个指标读数不会移除同一时刻的其他指标；图形会跨过手动排除点连接前后有效读数，原始缺失仍保留断点；只改变连线显示，不补值、不改变移动极差和能力指数的统计口径。能力指标与正态拟合随排除结果重新计算。点击 **恢复已排除的点** 后选择读数并确认，可撤销排除。

排除记录随账号隔离、自动恢复和完整JSON保存；管理员“加入数据”保留管理员自己的排除记录，不强行继承提交人的判断。定位包含来源、指标、装置、时间、分组和原始值；来源读数后来被修订为其他值时，旧排除不会套用到新读数。分析CSV明确列出被排除读数的原始值，完整JSON保留原始数据和排除记录。

### 前后能力分析

在 **数据分析 → 前后能力分析** 选择一个调整时间点、两个不重叠时段，或选择 **两组数据 / 不同指标**，直接比较不同装置/数据集中的两项指标。调整时刻归入“之后”。两组数据模式中，上方来源、指标和时间范围用于“之前”，下方单独选择“之后”的来源、指标、采样点和时间。兼容的单位会换算到之前指标的单位，不兼容时禁止比较；不会修改原始值。填写真实的规格下限 LSL / 规格上限 USL，可以只填一侧，也可填写范围内的目标值。

分析来源、指标、采样点、时间范围、规格限、子组大小、目标值、显著性水平、之后数据选择和统计表展开状态会自动记住；切出页面再返回或刷新都恢复上次状态，也包含在保存的JSON中。即使清空了某一输入，也保留空白，不会再次自动填充默认值。恢复文件时使用文件中的分析状态，管理员加入数据则保留管理员自己的状态。

在能力对比结果中增加 **I-MR前后对比控制图**。按时间划分时，拖动紫色虚线预览前后样本范围，松开后更新分界时间及三份报告；也可选中虚线使用左右方向键、Shift+方向键（10个节点）、Home/End。分界吸附到实际有效采样时间，支持秒和毫秒，分界时刻归入之后。MR不跨越前后分界、采样分组或明确空读数。

这张图固定使用个体值I-MR，前后分别估计控制限，不改变下方三份报告所设的子组大小。独立时段或不同数据的比较按两组采样顺序画在同一图中，固定分界对应两组定义；如需拖动，请点击“按时间划分并拖动”。对比图可单独导出PNG/SVG，也会附在完整分析报告中。

按参考版式生成三份完整报告：

- **汇总报告**：正态预测超规格相对变化箭头、均值/波动差异P值图、客户规格/目标、前后过程特征及变化量、实际整体能力分布和解释。
- **诊断报告**：前后Xbar-S控制图（子组大小1时为I-MR）、超3σ点标记、正态概率图、Anderson–Darling统计量及近似P值。
- **过程性能报告**：前后直方图、红色整体正态曲线和灰色组内曲线、N/子组大小/标准差、Cp/Cpk、Pp/Ppk、基准Z、观测/预测超规格百分比及PPM、变化量。

子组大小默认10，可设置1–100。按同一采样分组的时间顺序连续分组；请按实际合理子组设计设置。大小1采用 `移动极差均值 / 1.128`，大小2–100采用合并子组方差并作c4无偏修正。含明确空读数或不足2个值的子组不参与组内估计；尾组至少2个有效值时按实际大小参与并使用相应控制限。总体统计使用全部有效个体，界面显示排除数量。Pp/Ppk使用样本标准差（n−1）；单侧规格不计算Cp/Pp，无法估计非零波动时不显示无穷大指数。基准Z由预测总超规格概率反算，不简单等于3×Cpk。少于30个样本时提供探索性提示。

均值采用 **Welch双侧t检验**，波动采用 **中位数Levene双侧检验**，两组按独立样本处理，不做配对；波动降低/增加结合标准差方向解释。AD正态性检验至少需要8个有效样本，P值使用估计参数修正的近似公式；舍入和重复数值会影响结果。拒绝正态假设时明确标注正态模型预测值仅作参考，观测超规格比例仍直接从数据计算。控制图仅执行3σ单点超限规则，0个超限点不能证明过程稳定；显著变化不能单独证明改善原因。

每份报告可整页导出 **2400×1880 PNG** 或SVG，也可导出包含三份报告和完整统计表的独立HTML。**导出统计数据**保存前后指标、变化量和检验结果；**导出对比数据**同时保留来源、原值/原单位和换算后的比较值，便于核对。能力指数的解释仍依赖过程稳定、近似独立且近似正态；规格限由工艺或质量要求定义，与统计控制限不同。

### 自由作图与作图区

在 **数据分析 → 自由作图** 选择数据和指标，可制作 **折线、面积、柱状、散点、直方、箱线图**，修改标题、配色、时间和分组。配色扩展为12组，包括青蓝、明亮多彩、绿金、落日橙红、极光紫绿、海岛蓝橙、莓果玫紫、柑橘黄绿、经典宝蓝、柔彩、大地和色盲友好配色；可展开色卡预览，选择会随作图状态及保存的图表配置保留。同图最多6项指标；单位不同时需要勾选归一化或分别作图。散点图只使用同一记录中同时有效的横纵轴值；跨装置、不同采样时间的配对继续使用“关系分析”。柱状图可按日、周、月或采样分组计算有效值均值或求和；求和不是时间积分。

点击 **保存到作图区** 保存常用图表条件，最多24张。保存的是配置，展开图表时会读取当前数据，所以后续追加数据会自动反映在相应时间范围的图上。“载入编辑”可以修改后保存，也可以另存为新图表。配置按账号隔离，包含在完整备份中；管理员“加入数据”保留自己的作图区。

支持导出高清 PNG、SVG、带图表的独立 HTML 分析报告及 CSV 数据。大数据绘图会保留极值和缺口做显示抽样，统计和数据导出使用全部选中记录。时序/按采样点的箱线图最多同时展示20个分组，更多分组请通过筛选分别查看。手机可在图表内横向滑动。

## 网站与本机文档检索

网站的“文档检索”页提供 **下载 Windows 便携启动器** 和 **打开本机文档检索** 两个按钮。普通使用者可直接从网站下载安装包，完整解压后双击 **ProcessEngineerWorkbench.exe**，无需安装 Python或登录 GitHub。保留启动窗口，再点击 **打开本机文档检索**。每个人仍需 Windows、桌面版 Microsoft Office 及自己的文档权限。详见 [本地检索网站接入说明](本地检索网站接入说明.md)。

**Code → Download ZIP 是源码包，不是免安装 Python 的便携版。** 公开下载链接是 [最新版 Windows 便携启动器](https://github.com/SeanTim-could/Process-engineer/releases/latest/download/Workbench-Windows-Portable.zip)，可直接分享此链接。解压后请保留 `_internal` 目录。

发布到 `main` 的相关更新会在通过 Windows 构建与运行验证后自动发布 GitHub Release，网站的固定下载链接会指向最新成功发布的版本。构建失败时保留上一版下载。Release 文件不受 Actions 构建产物 30 天保留期限的限制。

本机启动器和它使用的本地 HTML 需要单独更新，不会随网站更新而自动替换。这个本机服务固定使用 8765 端口；做静态网页预览时请选用其他端口。

## 本地开发与验证

网页部分已经打包为单个 HTML 文件，不需要安装前端依赖或构建。本机文档检索需要上述 Windows 环境。在仓库根目录执行以下命令，可预览静态网页：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

用浏览器访问该服务，验证首页跳转及工作台功能。验证数据分享时，使用两个独立浏览器配置，分别模拟发送方和接收方，检查 CSV 导入、JSON 备份恢复及刷新后的数据保留。

检索逻辑与本机 HTTP 测试：

```sh
cd local_service
python3 -m unittest -v test_documents test_web_entry
```

这些测试使用模拟文档读取器，不代表 Windows Office 或公司文档权限已完成实测。

跨装置计算模块保存在 `frontend/cross-unit-calculations.js`。修改后执行以下命令，将模块同步到单文件网页：

```sh
python3 scripts/sync-cross-unit-calculations.py
python3 scripts/build-web.py
```

浏览器回归测试需要 Node.js、Playwright 和 Chromium，使用隔离的浏览器上下文及虚拟装置数据，不会读取已有工作空间：

```sh
node scripts/test-cross-unit-calculations.cjs
```

可用 `CHROMIUM_PATH` 指定浏览器路径。测试覆盖跨装置生产/LIMS引用、时间匹配、单位变化、后续导入重算、计算依赖、循环引用、备份迁移与实际编辑器操作。GitHub Actions 会自动运行该检查。

修改账号模块后运行 `python3 scripts/sync-account-auth.py`，再运行 `python3 scripts/build-web.py`，同步生成网站入口和缓存资源。网站生成不会拆分便携包使用的单文件 HTML。`node scripts/test-web-entry.cjs` 会阻止重型脚本响应，验证登录页仍能先显示，并检查旧网址、登录后加载和网络超时反馈。

管理员追加合并模块位于 `frontend/backup-merge.js`，使用同一个账号同步脚本嵌入。`node scripts/test-managed-accounts.cjs` 同时运行 `scripts/test-backup-merge.cjs`，验证权限、实际预览与提交、合并前备份、来源隔离、重复与增量数据、冲突保护、公式和月报、过期预览及备份往返。

统计、图形与分析工作区源码分别位于 `frontend/analysis-math.js`、`frontend/analysis-plots.js`、`frontend/data-analysis.js`。修改后执行 `python3 scripts/sync-data-analysis.py` 和 `python3 scripts/build-web.py`；网站生成也会自动同步分析模块。执行 `node scripts/test-analysis-math.cjs` 校验独立数值参考，`node scripts/test-data-analysis.cjs` 验证真实页面、前后时段、图形导出、保存与备份恢复及手机导航。

三份能力报告的统计和呈现位于 `frontend/capability-math.js`、`frontend/capability-reports.js`，由同一个同步脚本嵌入。`node scripts/test-capability-math.cjs` 使用SciPy独立参考值校验Welch、Levene、AD、c4合并子组、正态尾概率和基准Z；`node scripts/test-capability-reports.cjs` 验证636个样本/大小10的子组、不同指标及单位换算、三份PNG/SVG/HTML/CSV导出和原始数据保护。

分析工作状态与文件操作的源码分别位于 `frontend/analysis-drafts.js`、`frontend/capability-split-chart.js`、`frontend/workspace-files.js`。`python3 scripts/build-web.py` 自动同步分析与文件模块；也可单独执行 `scripts/sync-workspace-files.py`。`node scripts/test-analysis-session.cjs` 验证导航/立即刷新/文件恢复、拖动及键盘分界、毫秒节点和12组配色；`node scripts/test-workspace-files.cjs` 使用真实的隔离OPFS文件句柄/写入流和IndexedDB，只模拟选择对话框，验证保存、另存为、打开、重载、失败及下载模式。

新增功能回归：`node scripts/test-analysis-point-math.cjs` 检查定位、原值保护、移动极差断点和括号规范化；`node scripts/test-process-capability-and-points.cjs` 验证实际公式计算/括号编辑、时序过程能力、图上与明细选点、LIMS/自动图表/前后报告/自由作图同步、刷新与JSON恢复、并发冲突、日报派生指标和手机窗口。账号套件同时检查排除记录的账号隔离。
